# 筛图神器

macOS 14+ 原生图片筛选与对比工具，使用 SwiftUI、AppKit 和 ImageIO。支持文件夹分组、文件名优先配对、缩略图内容补配、大图叠图、像素容差、自定义 P 标签、本地旋转及按目录范围分类导出。

## 开发与验证

在项目目录运行：

```bash
swift build
swift test --no-parallel
swift run PhotoTriageMac
```

项目结构：

- `Sources/PhotoTriageCore`：索引、配对、状态、文件操作与导出。
- `Sources/PhotoTriageUI`：主面板、大图、容差、缓存、设置与快捷键。
- `Sources/PhotoTriageMac`：App 入口。
- `Tests`：功能、图像处理、文件安全和并发回归测试。
- `packaging`：版本、应用清单、图标、安装说明、修复脚本及正式打包流程。
- `docs`：排查与修复记录。

## 正式打包

```bash
bash packaging/build-release.sh --desktop
```

版本号来自 `packaging/VERSION`。脚本先运行测试，再构建 arm64 和 x86_64，合并通用二进制、签名并校验，生成含修复脚本的 DMG 和校验文件。每次 App 使用独立构建号；同版本已有 DMG 时停止，不覆盖。源码快照保存在 dist 中，便于追溯。公开发布前仍应在真实 Intel Mac 和另一台未安装过的 Mac 上验证安装。

当前为 ad-hoc 签名，未配置开发者证书或公证凭据。脚本不会关闭系统安全策略，也不会操作其他 App。DMG 下载文件本身损坏需要重新下载，不能用应用修复脚本修复。

## 数据与精度

- 导出复制文件，不移动或删除原图；以侧边栏选中的目录为范围，不按搜索结果缩小范围。
- JPEG/HEIF 的无损旋转依赖方向元数据；不支持安全写入的格式报错，不静默有损重编码。
- 首份旋转原图备份位于用户资源库 `Application Support/PhotoTriageMac/RotationOriginals`，恢复方法见安装说明。
- 容差默认快速预览，可切到原图逐像素检测。显示图缩小时保留局部最大差异，计数按实际分析像素计算；超过安全内存预算时明确提示。
- 会话评分与 P 标签退出时清理，这是既有设计；快捷键与滚动设置可自定义。已移除 Finder 颜色标签功能，不清除文件原有 Finder 标签。
- P 标签区的“编辑标签”或“设置 → P 标签”可修改所有 P 标签名称，并新增 P3、P4…；名称设置重启保留。导出分类文件夹使用标签名称，原图片文件名不变；同名、空名称及非法路径字符会被阻止。大图对比模式下，`⌘1–⌘9` 给整组图片打 P 标签；鼠标移到某张图片上方后，`⌥⌘1–⌥⌘9` 只给悬停图片打 P 标签，`⌘0` / `⌥⌘0` 分别对应 P9。
- 大图右键可直接编辑 P 标签名称或新增标签。默认 ⌘1–⌘9 对应 P0–P8，⌘0 对应 P9；P10 及以后通过菜单使用。原 W/E/R 默认已取消，改名不改变快捷键对应编号。
