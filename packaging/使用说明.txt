筛图神器 v1.3.8

安装
1. 打开 DMG。
2. 把“筛图神器.app”拖到“Applications”。
3. 从“应用程序”文件夹打开。

打不开或提示“已损坏”
1. 先把 App 拖入“应用程序”。
2. 双击 DMG 内的“打不开时运行.command”。
3. 如果脚本被拦截，请右键脚本，选择“打开”。

本次修复
- 快捷键统一按物理键位识别，支持主键盘、小键盘和空字符输入，修复 P 标签漏响应。
- 按住 Command 连续按数字，替换当前图片／组的 P 标签，不自动跳到下一张。
- 自定义快捷键如有重复或占用常用系统保留组合，会提示冲突并禁止保存。
- 移除所有 Finder 颜色标签功能，保留原文件已有标签不改动。
- 大图右键可编辑 P 标签名称、新增 P3、P4…，导出分类文件夹使用标签名称。
- P 标签快捷键改为 Command + 1～9 对应 P0～P8，Command + 0 对应 P9。
- 大图对比中，鼠标移到目标图片上方后按 Option + Command + 1～9，可只给悬停图片打 P0～P8；Option + Command + 0 对应 P9。
- 优化多文件夹、大批量对比的配对、滚动和翻组速度，缺图统计不再反复扫描全部图片。
- 后缀版本按 _1、_2、_3、_10 连续排列，缺图保留占位；尺寸加载不再重排整个列表。
- 优化 2 万张图片工作区的加载、刷新和统计计算，减少批量图片卡顿。
- 修复 Shift + 数字旋转后，按 Q 或数字叠图仍显示旧角度的问题；隐藏叠图刷新中断后会恢复加载。
- 修复快速连续打标的覆盖乱序，同一图片的旋转会依次执行。
- JPEG/HEIF 支持无损方向旋转；不支持安全旋转的格式会提示，不会强行压缩原图。
- 修复多目录缺图误报、内容配对候选不足及大图空位未同步的问题。
- 优化批量选择、缓存和文件变更刷新。
- 导出显示进度，可停止；失败项单独提示，重试跳过内容一致的已导出文件。
- 容差侧面可勾选“原图精密检测”，首次计算较慢，但逐个检查原图像素。
- 完整变更见“更新说明.md”。

旋转备份
- 首份原文件备份保存在用户资源库：Application Support/PhotoTriageMac/RotationOriginals。
- Finder 中按 Command + Shift + G，输入 ~/Library/Application Support/PhotoTriageMac/RotationOriginals 即可查看。
- 各子目录的“原路径.txt”记录来源；恢复前退出 App，先保留当前图片，再将备份复制回原路径。
- 备份不会自动删除，会占用磁盘空间。

导出与容差
- 导出以侧边栏选中的文件夹为范围；搜索和分类不改变该目录范围。
- 停止导出会在当前文件复制结束后停止，已经完成的文件保留。
- 导出结果包含成功、跳过和失败信息；目标文件夹中的隐藏 JSON 文件保存详细清单。
- 原图精密检测超过本机安全内存预算时会提示，不会静默降低检测精度。
- 显示图可能缩小，红点会保留细小差异；准确数量以统计栏为准。

功能速览
- 大幅优化“刷新”速度：减少重复扫描，不再读取 Finder 标签。
- 刷新时保留图片顺序、当前选中和已加载画面，未变化图片不再重新解码或闪屏。
- 文件内容变化时只刷新对应图片，不影响同组的其他图片。
- 丢失图片改为按文件名精准匹配，避免中间少一张导致后续图片全部错位误报。
- “丢失图片”数字按实际缺少的文件数统计。
- 大图对比按原图像素显示：不再限制 3200px，放大时逐级加载到原图完整分辨率。
- Retina 屏幕按实际显示像素加载高清画面，高清加载期间保持当前画面不黑屏。
- 修复查看“未处理”时，变更标签后大图对比和缩略图跳回第一张的问题。
- 改标签时保持当前对比组、图片顺序、聚焦图片和横向滚动位置不变。
- 单图连续处理会准确进入原来的下一张，不再跳回开头或跳过图片。
- 同文件夹对比按文件名顺序分组；首组选 4 张，后续组也保持 4 张。
- 容差图只分析原图一次，拖动滑杆时快速重新着色，刷新更快。
- 通过率按当前范围计算：100% 减去淘汰（badcase）占比，未处理图片不再被误算为淘汰。
- 优化 Q 叠图切换：图片提前缓存，按住或松开时不再闪动、变色。
- 优化数字键叠图：从多图总览进入大图详情时直接显示已缓存图片，减少闪屏。
- 主界面点击“设置”，或按 Command + , 打开设置窗口。
- “滚动与缩放”可开关滚轮缩放，并切换自然滚动方向。
- “快捷键”中点击按键框，即可录入自己的按键或组合键。
- 快捷键冲突会标红；可随时恢复默认。

默认快捷键
- A / S / D：保留 / 恢复 / 淘汰
- Command + 1～9：P0～P8；Command + 0：P9。P10 及以后通过右键菜单选择。
- 大图对比：先把鼠标移到目标图片上方，再按 Option + Command + 1～9 给该图打 P0～P8；Option + Command + 0 给该图打 P9。
- 按住 Command 不放，连续按数字即可替换当前图片／组的 P 标签，不自动跳到下一张。支持主键盘和小键盘，不受输入法影响。
- 自定义快捷键如有重复或占用常用系统快捷键，会提示冲突并禁止保存。
- 大图右键“编辑 P 标签名称…”或“新增 P 标签…”，也可在主面板“编辑标签”中修改；编辑后点击保存。名称设置重启保留，改名不改变编号。
- 新增 P 标签可在图片右键菜单或侧栏操作区使用；导出勾选对应标签，分类文件夹使用该名称，图片文件名不变。
- Shift + 1～9：旋转大图中对应图片，并同步本地文件
- 主界面多选后按空格：进入对比
- B：上一组；空格或 ↓：下一组；0：显示或隐藏容差图

系统要求：macOS 14 或更高版本，支持 Apple 芯片与 Intel Mac。
修复脚本只处理 /Applications/筛图神器.app，不会修改其他应用或文件。
如果 DMG 本身打不开、校验失败或下载不完整，请重新下载；修复脚本不能修复磁盘镜像数据。
应用为 ad-hoc 签名，未进行开发者证书签名或公证。
